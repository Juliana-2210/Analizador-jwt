📊 Flujo de Datos Principal
1️⃣
Crear Token
Usuario → Flask → encoder.py → Genera JWT (Header.Payload.Signature) → mongodb.py → Guarda en MongoDB → Respuesta
2️⃣
Analizar Token
Usuario → Flask → lexer.py (Tokenización) → parser.py (Sintaxis) → semantic.py (Validación) → crypto_verify.py (Firma) → mongodb.py → Respuesta detallada
3️⃣
Ver Tokens
Usuario → Flask → /api/tokens → TokenRepository.get_all_tokens() → MongoDB Atlas → Lista ordenada → Interfaz
4️⃣
Eliminar Token
Usuario → Flask → /api/tokens/<id> DELETE → TokenRepository.delete_token() → MongoDB → Confirmación → Recarga
