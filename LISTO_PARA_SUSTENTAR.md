---

## 🎯 CÓMO VERLO

### 1️⃣ Inicia el servidor
```bash
python app.py
```

### 2️⃣ Abre la web
```
http://localhost:5000
```

### 3️⃣ Haz clic en "Casos de Prueba"
Nueva pestaña con 27 tests organizados en 4 categorías

### 4️⃣ Prueba uno
Haz click en "Probar" → Se ejecuta el análisis automáticamente
